🎢 Guest Journey at the Park

Semnox vs Hello Park — Who Does What

1
SEMNOX
📱 Guest scans QR code and fills out registration form
Parent's full name, phone, email, children's names, dates of birth.
Everything happens in the Semnox system.
➡️ Semnox calls HP API → registration data (parent + children + DOB)
2
SEMNOX
💳 Guest pays for tickets at POS
Cashier processes the receipt in Semnox POS terminal. Selects a package (time-based, full day, etc.).
3
SEMNOX
⌚ Cashier binds RFID wristband to a child
Directly in the Semnox POS interface. Cashier scans the wristband → system links it to the child's profile.
Single interface, single POS — no second screen needed.
➡️ Semnox calls HP API → wristband bound (child_id + rfid_uid)
4
SEMNOX
🚧 Child passes through turnstile
Semnox validates the wristband, opens the gate, starts session timer (if time-based package).
➡️ Semnox calls HP API → child entered the park (entry_time, session)
🎮 Hello Park Play Area
5
HELLO PARK
🕹️ Child taps wristband at Hello Park attraction
Our RFID reader at the attraction reads the wristband number.
We already know who this child is — because we received the API call at step 3.
⬅️ HP calls Semnox API → validate wristband, get child details
6
HELLO PARK
🧑‍🎤 Avatar and game progress is loaded
The child plays on attractions. Progress is saved in our system.
On the next visit — progress is restored!
🔄 End of Visit
7
SEMNOX
🔙 Child leaves, returns wristband
Semnox unbinds the wristband from the child. The wristband is now ready for reuse by the next guest on the same day.
➡️ Semnox calls HP API → wristband unbound → we clear the game session from this band
🔄 Scenario A: Same-Day Wristband Reuse
A
🔁 Wristband is returned and reassigned to a new child
1. Emma leaves the park, returns wristband #A001
2. Semnox unbinds #A001 from Emma
3. Semnox calls HP API → unbind → we clear Emma's game session from #A001
4. New guest Liam arrives, cashier assigns #A001 to Liam
5. Semnox calls HP API → bind (Liam + #A001)
6. Liam taps the wristband at attraction → Hello Park creates a new Avatar for Liam ✅
📅 Scenario B: Returning Guest (Next Day / Next Week)
B
📅 Emma comes back the next day
1. Emma returns to the park (next day or next week)
2. Cashier finds Emma in Semnox by phone number / QR code / name
3. New wristband #B007 is assigned to Emma
4. Semnox calls HP API → bind (Emma + #B007) — same child_id as before!
5. Emma taps #B007 at Hello Park attraction
6. HP recognizes Emma by child_id → loads SAVED game progress from previous visit 🎮✅
⚠️ CRITICAL: Semnox must send the same child_id on every visit so we can restore game progress
